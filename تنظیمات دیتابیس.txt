در داکر قسمت image کانتینر postgres  نسخه نهایی را نصب کردم و میخواهم run  کنم برای اجرای سامانه bonyancore. در پنل تنظیمات از من مشخصاتی میخواهد شامل:
نام کانتینر،host port، host path,enviroiment variable  می باشد.
تنظیماتش چیست
با توجه به معماری پروژه Bonyan Core و نیازمندی‌های شما، تنظیمات دقیق برای اجرای کانتینر PostgreSQL در پنل مدیریت Docker (مانند Docker Desktop یا Portainer) به شرح زیر است:

⚙️ تنظیمات دقیق برای اجرای کانتینر PostgreSQL
۱. نام کانتینر (Container Name)
text
bonyan_postgres
این نام برای شناسایی کانتینر در شبکه داکر استفاده می‌شود. در فایل docker-compose.yml نیز از همین نام استفاده شده است.

۲. پورت میزبان (Host Port)
text
5432
این پورت روی سیستم شما (ویندوز) به پورت ۵۴۳۲ داخل کانتینر متصل می‌شود. اگر پورت ۵۴۳۲ روی سیستم شما اشغال است، می‌توانید از پورت دیگری مانند 5433 استفاده کنید.

۳. مسیر میزبان (Host Path) برای Volume
text
C:\docker\volumes\bonyan_postgres_data
این مسیر روی سیستم شما برای ذخیره‌سازی دائمی داده‌های دیتابیس استفاده می‌شود. می‌توانید هر مسیری که دوست دارید انتخاب کنید، ولی بهتر است از یک مسیر مشخص و قابل دسترس استفاده کنید.

نکته: در Docker Desktop، این قسمت معمولاً با عنوان Host Path یا Volume Mount شناخته می‌شود.

۴. متغیرهای محیطی (Environment Variables)
متغیر	مقدار	توضیح
POSTGRES_USER	bonyan	نام کاربری برای اتصال به دیتابیس
POSTGRES_PASSWORD	bonyan123	رمز عبور کاربر دیتابیس
POSTGRES_DB	bonyan_core	نام دیتابیس پیش‌فرض که ایجاد می‌شود
PGDATA	/var/lib/postgresql/data/pgdata	(اختیاری) مسیر ذخیره‌سازی داده‌ها در داخل کانتینر
۵. تصویر (Image)
text
postgres:17-alpine
یا

text
postgres:16-alpine
(نسخه ۱۶ پایدارتر و پشتیبانی‌شده‌تر است)

📋 خلاصه تنظیمات در قالب جدول
بخش	مقدار
Image	postgres:17-alpine
Container Name	bonyan_postgres
Host Port	5432

Container Path	/var/lib/postgresql/data
POSTGRES_USER	bonyan
POSTGRES_PASSWORD	bonyan123
POSTGRES_DB	bonyan_core
🚀 دستور معادل در خط فرمان (PowerShell)
اگر بخواهید همین تنظیمات را با دستور docker run اجرا کنید:

powershell
docker run -d `
  --name bonyan_postgres `
  -e POSTGRES_USER=bonyan `
  -e POSTGRES_PASSWORD=bonyan123 `
  -e POSTGRES_DB=bonyan_core `
  -p 5432:5432 `
  -v C:\docker\volumes\bonyan_postgres_data:/var/lib/postgresql/data `
  --restart unless-stopped `
  postgres:17-alpine
🔗 اتصال از برنامه FastAPI به این دیتابیس
در فایل .env پروژه Bonyan Core، آدرس اتصال را به صورت زیر تنظیم کنید:

text
DATABASE_URL=postgresql://bonyan:bonyan123@localhost:5432/bonyan_core
✅ بررسی نهایی
پس از اجرای کانتینر با تنظیمات فوق:

در Docker Desktop، وضعیت کانتینر را به صورت Running ببینید.

از طریق ابزار مدیریت دیتابیس مانند pgAdmin یا DBeaver با مشخصات زیر وصل شوید:

Host: localhost

Port: 5432

Username: bonyan

Password: bonyan123

Database: bonyan_core

💡 نکته مهم برای فایل docker-compose.yml
اگر از فایل docker-compose.yml استفاده می‌کنید، تنظیمات معادل به این صورت است:

yaml
services:
  db:
    image: postgres:17-alpine
    container_name: bonyan_postgres
    environment:
      POSTGRES_USER: bonyan
      POSTGRES_PASSWORD: bonyan123
      POSTGRES_DB: bonyan_core
    ports:
      - "5432:5432"
    volumes:
      - C:/docker/volumes/bonyan_postgres_data:/var/lib/postgresql/data
    restart: unless-stopped
با این تنظیمات، دیتابیس شما آماده اتصال به سامانه Bonyan Core خواهد بود.
