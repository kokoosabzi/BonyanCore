# سیستم حسابداری

نسخه اول پروژه دارای حسابداری دوبل (Double Entry Accounting) است.

تمام عملیات مالی که اثر مالی دارند، باید در نهایت منجر به تولید سند حسابداری شوند.

اصل:

هیچ عملیات مالی بدون سند حسابداری نباید باقی بماند.

============================================================

# مدل ثبت اسناد

دو روش ثبت سند وجود دارد.

------------------------------------------------------------

روش اول

Automatic Journal Entry

سیستم به صورت خودکار سند حسابداری ایجاد می‌کند.

نمونه‌ها

- ثبت فیش
- پرداخت
- دریافت
- انتقال بین حساب‌ها
- ثبت وام
- ثبت یارانه
- ثبت مابه‌التفاوت

------------------------------------------------------------

روش دوم

Manual Journal Entry

حسابدار می‌تواند سند دستی صادر کند.

این قابلیت فقط برای کاربران دارای سطح دسترسی مجاز فعال است.
